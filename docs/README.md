# Документация проекта

## Архитектура

Начните с [обзора архитектуры](architecture/README.md): назначения продукта,
границ компонентов и состояния реализации.

- [Предметная модель](architecture/domain-model.md) — понятия, идентичность,
  применимость, переводы и неполные знания.
- [Пользовательские сценарии](architecture/user-journeys.md) — выбор протокола,
  чтение, наполнение агентами и предполагаемый дев-редактор.
- [Матрица таблиц](architecture/table-matrix.md) — реализованная SQL-структура.
- [Контракт базы](architecture/database-contract.md) — API, валидация,
  транзакции, удаление и конкурентная запись.
- [Обмен данными](architecture/data-exchange.md) — снимок таблиц, короткие
  стабильные имена, импорт и публикация экспорта.
- [CLI и MCP](architecture/interfaces.md) — продуктовые интерфейсы для агента
  и автоматическое обновление read-only кеша.
