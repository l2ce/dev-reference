# Проверка регионального каталога

Проверка завершена 6 ноября 2026 года.

## Результат

- Схема 20: 36 таблиц, 564 предметные записи.
- Сохранены 124 протокола без `rev`, 84 хроники и 116 выпусков.
- Восстановлены 233 региональных контекста и 326 связей с протоколами.
- Все 171 исходное соответствие «выпуск / номер» и UUID прежних сущностей сохранены.
- Страны и даты не заполнены; сведения L2ELO не внесены.
- Основной порядок ориентирован на Akumu; дополнительные хроники отделены.

Резервная копия до изменения схемы:
`packages/database/.local/backups/catalog-regions-v20-2026-11-05/before.sqlite`.
Экспорт → импорт → экспорт дал побайтовое совпадение всех 2022 JSON-файлов.

## Браузерные сценарии

Проверены `http://localhost:3000/protocols/` и production preview
`http://127.0.0.1:4187/`. Использован проектный agent-browser, отдельные сессии
`catalog-v20-20261105` и `catalog-v20-nojs-20261105`, без пользовательского профиля.

Проверочные браузерные сессии закрыты, временный preview на порту 4187 остановлен.
Сервер пользователя на `localhost:3000` не останавливался; финальная таблица
дополнительно проверена по этому адресу.

- RU/EN: прямое открытие каталога и страницы хроники.
- Смена языка RU → EN сохраняет страницу Gracia.
- Номер `273`: High Five / NA и Homunculus / KR, без смешения регионов.
- Поиск `286` раскрывает дополнительное совпадение Tales Untold.
- Переход в хронику и назад восстанавливает `q=273`.
- Фильтр материалов показывает пустое состояние; сброс возвращает каталог.
- Название выпуска открывает соответствующий якорь страницы хроники.
- Источники конкретного регионального выпуска раскрываются.
- На 390×844 работает горизонтальная прокрутка с клавиатуры; название хроники
  остаётся закреплено слева, вся страница не переполняется по горизонтали.
- Проверены светлая и тёмная темы.
- Серверный HTML содержит заголовки и таблицы; RSC payload присутствует.
- В отдельной сессии Chromium с отключённым JavaScript подтверждены заголовок
  и шесть таблиц каталога при отсутствии Next.js bootstrap.
- Неизвестная хроника возвращает HTTP 404.
- Ошибок приложения и гидратации не обнаружено.
- Axe: каталог и страница хроники — 0 нарушений, 0 незавершённых проверок
  в проверенных состояниях; обрезанные горизонтальной прокруткой элементы
  дополнительно проверены визуально.

Отдельный скриншот режима без JavaScript получить не удалось из-за таймаута
`Page.captureScreenshot`; HTML/DOM этого режима проверены отдельно.
