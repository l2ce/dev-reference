# Время экспорта и импорта

Бенчмарк всегда выполняет **один экспорт и один импорт**, затем проверяет
совпадение данных. Дата приведённых замеров: **29 октября 2026 года**.

Условия этих замеров — формат JSON 8 с отдельной коллекцией источников.
Начиная с формата 9 источники хранятся внутри записей; текущий скрипт использует формат 15.

## Контрольный запуск на 5 000 записях

| Операция    |       Время |
| ----------- | ----------: |
| **Экспорт** | **1,899 с** |
| **Импорт**  | **2,126 с** |

Набор: 2 514 сущностей и 2 486 вариантов, по 2 500 записей на язык.
Операции выполнены в настоящем TTY высотой 24 строки. Конечное содержимое
терминала проверено: после каждой операции все 14 строк коллекций показывают
100%, оба языковых блока расположены корректно.

| Этап                             | Экспорт |  Импорт |
| -------------------------------- | ------: | ------: |
| Сканирование / открытие          | 0,001 с | 0,113 с |
| Чтение SQL / JSON                | 0,072 с | 0,487 с |
| Предметная проверка и подготовка | 1,265 с | 1,334 с |
| Запись JSON / SQLite             | 0,559 с | 0,133 с |
| Фиксация и завершение            | 0,001 с | 0,058 с |

Данные после переноса совпадают; `quick_check` возвращает `ok`, нарушений
внешних ключей нет. Основная доля времени приходится на валидацию.

Артефакты этого запуска:

```text
packages/database/.local/benchmarks/sqlite-5000-FiYGh3/
  source.sqlite
  data/
  restored.sqlite
  results.json
  REPORT.md
  terminal.log
```

## Запуск и условия

```bash
pnpm data:build
pnpm --filter @l2ce/database benchmark --records 5000
```

- Реальный исходный снимок дополнен явно синтетическими записями всех семи коллекций.
- Описания синтетических записей содержат 1024 байта Markdown с разметкой и ссылкой.
- Каждая операция использует отдельный процесс Node.js и штатный прогресс CLI.
- Создаются новый каталог экспорта и новый SQLite-файл назначения.
- Полное время включает чтение, проверку, I/O, фиксацию и вывод прогресса.
- Подготовка набора и проверка переноса измеряются отдельно от экспорта/импорта.
- Кеш ОС сохраняется; импорт выполняется сразу после экспорта.
- Node.js 24.18.1, Linux x64, AMD Ryzen 5 7600X, SSD NVMe, ext4.

Режим вывода (`tty` или `non-tty`) и длительности этапов записываются в отчёт.
Этап валидации также включает подготовку до записи первого файла.

# Примечание о формате данных

Приведённые выше замеры относятся к прежней универсальной SQL-схеме.
Для текущих предметных таблиц формата 15 требуется новый замер. Текущий генератор создаёт
синтетические предметные сущности и их имплементации, сохраняя по две служебные записи
на локаль.
